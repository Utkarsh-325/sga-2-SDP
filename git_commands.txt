1. git init
   Initializes a new empty local Git repository in the current project folder.

2. git branch -M main
   Renames the default branch to 'main'.

3. git status
   Displays the state of the working directory and staging area, showing tracked, untracked, and modified files.

4. git add <file> / git add .
   Stages specified file changes (or all changes in the directory) for the next commit.

5. git commit -m "<message>"
   Records staged snapshots permanently in the repository's version history with a descriptive message.

6. git branch feature
   Creates a new branch named 'feature' for isolated development without affecting 'main'.

7. git checkout <branch>
   Switches the active working directory to the specified branch ('feature' or 'main').

8. git merge feature
   Integrates the commit history and changes from the 'feature' branch into the active 'main' branch.

9. git log --oneline --graph --all
   Displays a compact visual commit history graph across all branches in the repository.

10. git reset --soft HEAD~1
    Undoes the most recent commit by moving HEAD back one commit while keeping changes staged.

11. git remote add origin <url>
    Connects the local Git repository to the remote GitHub repository under the alias 'origin'.

12. git push -u origin main
    Uploads all local commits on the 'main' branch to the remote GitHub repository and sets upstream tracking.
